# CraveCraft

Crave it. Learn it. Make it. AI-powered cooking platform, created by Ethan Samuel (ENGR 310).

Phase 1: one-page landing site (Next.js, React, TypeScript, Tailwind CSS).

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build check
```

Planned: Neon PostgreSQL, authentication, OpenAI (CraveChef AI), Stripe, Vercel.
